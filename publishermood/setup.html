من الإعداد إلى النشر.

دليل متسلسل لتشغيل مساحة نشر خاصة بك دون قاعدة بيانات، مع تخزين GitHub مشفّر وتوليد Gemini ونشر Telegram.

1. جهّز مساحة نشر مستقلة

هذه النسخة مخصصة لمالك واحد لكل مشروع Vercel. لتشغيلها لأشخاص آخرين، ينشئ كل شخص مشروعًا ومفاتيح منفصلة. لا تستخدم مفاتيح AutoPublisher الشخصي ولا تخزنها في الكود أو المتصفح.

  1. أنشئ مستودع GitHub خاصًا للتخزين، مع README أو أي ملف لتهيئة الفرع الرئيسي.
  2. أنشئ Fine-grained token محددًا لهذا المستودع فقط مع Contents: Read and write.
  3. أنشئ مفتاحًا مجانيًا من Google AI Studio دون تشغيل الفوترة.
  4. أنشئ بوتًا من @BotFather، ثم أضفه مشرفًا إلى قناتك العامة بصلاحية نشر الرسائل فقط.
  5. ولّد ثلاث قيم قوية ومختلفة (32 حرفًا عشوائيًا على الأقل، ويفضل 64): ADMIN_PASSWORD وSTATE_KEY وCRON_SECRET. احفظها في مدير كلمات مرور، ولا تغير STATE_KEY بعد حفظ البيانات دون خطة ترحيل.

2. أضف متغيرات Vercel

افتح مشروعك في Vercel → Settings → Environment Variables، اختر Production، وفعّل Sensitive للمفاتيح. احفظ ثم أعد النشر. لا تُدخل مفاتيح الخدمات في هذه الصفحة.

فتح Vercel ↗

اختياري: GH_BRANCH (main افتراضيًا)، GEMINI_MODEL (gemini-3.1-flash-lite)، PUBLISH_TIMEZONE (Asia/Hebron). الجدولة المجانية المرفقة تعمل عبر 05:00 و06:00 UTC مع شرط الساعة 08 المحلية؛ لمناطق أخرى عدّل توقيت cron بما يلائمها. لا تضمن الخطة المجانية الدقيقة المحددة.

3. تسجيل الدخول ومتابعة التفعيل

لا توجد نتائج فحص حتى تسجيل الدخول.

0 من 8 مفاتيح

يُعاد فحص الربط كل 90 ثانية أثناء فتح الصفحة وتسجيل الدخول. فحص Gemini يختبر الوصول إلى النموذج؛ اختبار التوليد الحقيقي منفصل. لا يتم إرسال رسالة أثناء فحص القناة.

4. الهوية التحريرية والأتمتة

عند تعطيله، لا ينشر المجدول. التوليد اليدوي يبقى مسودة. التحقق العلمي الآلي ليس ضمانًا مطلقًا.

5. اختبار دورة التشغيل

توليد مسودة حقيقية وحفظها دون إرسال. اختر النشر اليدوي فقط بعد مراجعة النص.
