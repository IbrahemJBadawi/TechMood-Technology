# CodeMood | كود مود

تطبيق تعلّم البرمجة التفاعلي ضمن TechMood Technology.

## المنجز في النسخة 0.1
- واجهة عربية RTL متجاوبة مع الهاتف، مبنية على هوية TechMood وGrowthMood.
- Cairo وPlus Jakarta Sans، وأيقونات SVG خطية محلية (بدون CDN لأيقونات JavaScript).
- 7 دروس تفاعلية في مسارين: Python وJavaScript. مسار الذكاء الاصطناعي قادم لاحقًا.
- قواعد تحقق تعليمية محلية لكل مثال، تلميحات، محرر نصي، ومحاولة إعادة.
- XP، قلوب، Streak، 6 شارات، تقدم المسارات، ترحيب أول زيارة.
- حفظ على الجهاز عبر localStorage، تعديل الاسم، تصدير ملف تقدم، ومسح التقدم.

**تنبيه مهم:** التحقق من الأكواد في هذه النسخة هو فحص نمطي تعليمي ولا يشغّل الأكواد تعسفيًا، وليس Python/JavaScript sandbox حقيقيًا. لا توجد حسابات مستخدمين أو قاعدة بيانات مستقلة أو مزامنة بين الأجهزة. لا يُعتمد على XP بوصفه موثوقًا لأنه محفوظ محليًا.

## النشر على Vercel
App type: Static. Root Directory: apps/codemood. لا يحتاج بناء ولا مفاتيح سرية.

## فصل المشروع
وُضع التطبيق داخل apps/codemood في مستودع TechMood-Technology على GitHub لأن اتصال GitHub الحالي لا يتيح إنشاء مستودع جديد. تطبيق Vercel مستقل، لكن مستودع GitHub ليس مستقلًا بعد. لا يتغير أي كود من المنتجات الأخرى.
